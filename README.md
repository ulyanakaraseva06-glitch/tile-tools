# Tile Tools

Единый сервис, который объединяет три существующих продукта:

- `sravni-plitku` - визуализатор плитки и существующая PHP/MySQL-база;
- `project_vilray_studio` - расчёт и раскладка плитки;
- `plitka-pdf` - редактор PDF-документов.

## Единый репозиторий

Исходный код всех трёх сервисов находится в этом репозитории:

- `source/sravni-plitku` - визуализатор;
- `source/project_vilray_studio` - расчёт плитки;
- `source/plitka-pdf` - PDF-редактор.

Это единый проект: после `git clone` другой разработчик получает оболочку и все внутренние сервисы. Папки `node_modules` и собранные файлы не хранятся в Git, потому что воспроизводятся командой установки.

## Стек объединённого сервиса

- общая оболочка и API: PHP 8+, MySQL/PDO, HTML/CSS и vanilla JavaScript;
- `sravni-plitku`: существующий PHP/JavaScript без переписывания;
- `project_vilray_studio`: существующие React 19, TypeScript и Konva;
- `plitka-pdf`: существующие React 18, TypeScript и Vite.

Смена стека внутренних приложений отменена: объединение выполняется через оболочку и интеграционные адаптеры.

## Текущий инкремент

Новый сервис объединяет оболочку, серверные общие сущности и встроенные исходники сервисов. Внутренняя логика каждого сервиса сохранена в своей папке `source/`.

### Быстрый старт окружения

1. Установить PHP, MySQL и Node.js. Для Windows рекомендован Laragon.
2. Скопировать `config.example.php` в `config.php` и указать закрытый `storage_root` вне web-root.
3. Создать базу MySQL, совместимую с исходной таблицей `users` из «Сравни плитку».
4. Для чистой локальной базы запустить миграции в порядке `000` → `001` → `002` → проверить `003` → `004` → `005` → `006` → `007` → `008` → `009` → `010`; сначала только на staging. Миграция `006` создаёт каталог демонстрационного оборудования, `007` — личные папки медиатеки, `008` — галерею вариантов рисунка одной модели плитки, `009` — безопасные токены длительного входа, `010` — временного администратора и счётчик посещений.
5. Один раз установить зависимости и собрать внутренние приложения:

   ```powershell
   .\scripts\setup-local.ps1
   ```

6. Импортировать системный каталог из встроенного источника:

   ```powershell
   php .\catalog\import_sravni_catalog.php --source=".\source\sravni-plitku" --copy-images
   ```

7. Запустить весь сервис:

   ```powershell
   .\scripts\start-local.ps1
   ```

8. Убедиться, что установлен PHP 8.1+, расширения `pdo_mysql`, `fileinfo`, `json`, `zip` и настроены `upload_max_filesize`/`post_max_size`.

После импорта 48 моделей из `source/sravni-plitku/catalog/tiles.json` появляются в общей медиатеке, калькуляторе и PDF-редакторе. В каталог уже включена поставка 31Lab: 31 модель и 267 пригодных изображений-граней. Повторный импорт безопасен: метаданные обновляются по стабильному ID, а уже скопированные изображения не дублируются.

Файл `Forest Oak_120x60_F6.jpg` в исходной поставке имеет размер 0 байт и поэтому намеренно не импортируется. После получения исправленного изображения его нужно положить в папку модели и повторно сформировать каталог.

Документация и статус решений — в `docs/`.
