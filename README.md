# Tile Tools

Единый сервис, который объединяет три существующих продукта:

- `sravni-plitku` - визуализатор плитки и существующая PHP/MySQL-база;
- `project_vilray_studio` - расчёт и раскладка плитки;
- `plitka-pdf` - редактор PDF-документов.

## Правило первой итерации

Исходные проекты не изменяются. Новый сервис собирается отдельно, а каждый продукт подключается в исходном виде и проходит проверку полного функционального соответствия.

## Стек объединённого сервиса

- общая оболочка и API: PHP 8+, MySQL/PDO, HTML/CSS и vanilla JavaScript;
- `sravni-plitku`: существующий PHP/JavaScript без переписывания;
- `project_vilray_studio`: существующие React 19, TypeScript и Konva;
- `plitka-pdf`: существующие React 18, TypeScript и Vite.

Смена стека внутренних приложений отменена: объединение выполняется через оболочку и интеграционные адаптеры.

## Текущий инкремент

Новый отдельный сервис объединяет оболочку, серверные общие сущности и будущие модули, не изменяя папки `sravni-plitku`, `plitka-pdf` и `project_vilray_studio`.

### Быстрый старт окружения

1. Скопировать `config.example.php` в `config.php` и указать закрытый `storage_root` вне web-root.
2. Создать базу MySQL, совместимую с исходной таблицей `users` из «Сравни плитку».
3. Для чистой локальной базы запустить миграции в порядке `000` → `001` → `002` → проверить `003` → `004` → `005`; сначала только на staging.
4. Импортировать системный каталог без изменения источника:

   ```powershell
   php .\catalog\import_sravni_catalog.php --source="C:\Users\ulyan\Desktop\sravni-plitku" --copy-images
   ```

5. Убедиться, что установлен PHP 8.1+, расширения `pdo_mysql`, `fileinfo`, `json`, `zip` и настроены `upload_max_filesize`/`post_max_size`.

Документация и статус решений — в `docs/`.
