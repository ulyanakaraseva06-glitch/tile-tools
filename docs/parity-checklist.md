# Чек-лист сохранения функциональности при переносе

Нельзя считать модуль перенесённым, пока каждый пункт ниже не проверен на исходной версии и в Tile Tools.

## «Сравни плитку»

- [ ] Каталог, фильтры и карточки используют те же постоянные `tileId`.
- [ ] Выбор интерьера, зон, применённой плитки, отмена/повтор и экспорт изображения работают с теми же исходными данными.
- [ ] Избранное синхронизируется с `tt_favorite_items`, а не отдельным localStorage.
- [ ] Сценарии гостя и авторизованного пользователя не теряют существующие ограничения доступа.

## «Посчитай плитку» / Vilray Studio

- [ ] Типы помещений, произвольный контур, размеры, несколько комнат и привязки сохранены.
- [ ] Проёмы, перегородки, зоны, раскладки, швы, смещения, повороты и материалы дают одинаковый расчёт.
- [ ] Исходное полотно React Konva работает внутри общей оболочки без изменения поведения.
- [ ] Расчёт, предупреждения, PDF-экспорт и история действий совпадают с утверждёнными fixtures исходного проекта.

## «Плитка PDF»

- [ ] Перенесены все существующие шаблоны, страницы, зоны и режим редактирования layout.
- [ ] Сохранены добавление/удаление/дублирование страниц, привязка товаров и изображений, настройки и JSON-импорт/экспорт.
- [ ] PDF сравнен визуально: формат, ориентация, отступы, изображения, шрифты, таблицы и номера страниц.
- [ ] localStorage заменён на `tt_projects` и `tt_media_assets`, но экспортируемые пакеты продолжают открываться в новом аккаунте.

## Сквозные проверки

- [ ] Файл 300 МБ отклоняется до записи в хранилище.
- [ ] Суммарные личные данные более 100 МБ отклоняются; системный каталог не попадает в личную квоту.
- [ ] Удалённое медиа недоступно пользователю, но может быть восстановлено до истечения 30 дней.
- [ ] Поставщик может публиковать общие материалы без модерации; действие зафиксировано в `tt_audit_events`.
- [ ] Пользователь не читает файл из папки другого пользователя по прямой ссылке или подмене mediaId.
