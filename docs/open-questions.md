# Открытые вопросы

Статус: `OPEN` - нужен ответ до реализации, `DECIDED` - решение зафиксировано в `docs/decisions/`.

| ID | Статус | Вопрос | Почему важен |
| --- | --- | --- | --- |
| Q-001 | DECIDED | Как устроена авторизация? | PHP-сессии и MySQL/PDO на базе «СравниПлитку»; без SSO без отдельного решения. |
| Q-002 | DECIDED | Какую квоту получает пользователь и поставщик? | Максимум 100 МБ для всех ролей. |
| Q-003 | DECIDED | Сколько дней хранить удалённый файл до физического удаления? | Soft delete, затем очистка через 30 дней только при отсутствии ссылок из проектов. |
| Q-004 | DECIDED | Кто получает заявки из «Оборудования» и «Услуг»? | Заявка уходит одновременно на e-mail и Telegram. Точные адрес и бот нужны перед подключением. |
| Q-005 | DECIDED | Какие PDF-пресеты обязательны в первом релизе? | Перенести все существующие пресеты «Плитка PDF». |
| Q-006 | DECIDED | Может ли поставщик публиковать общие материалы сам? | Да. Поставщик публикует общие материалы без модерации. Все действия записываются в аудит. |
| Q-007 | DECIDED | Нужны ли личные и командные проекты одновременно? | В MVP проекты личные, но их можно скачать в переносимом файле и импортировать в другой аккаунт. Совместное редактирование - отдельный этап. |

Нельзя закрывать вопрос предположением. Если решение принято, создать файл в `docs/decisions/` и изменить статус на `DECIDED`.
