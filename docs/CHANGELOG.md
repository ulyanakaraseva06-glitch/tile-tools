# Changelog

## 2026-09-24 — минимальная панель администратора

- Добавлен временный локальный администратор с логином, паролем и никнеймом `admin`; пароль хранится только как безопасный хеш.
- В общей медиатеке администратор может создать новую карточку плитки, загрузить изображение и заполнить основные характеристики. Добавленная модель сразу доступна общим сервисам.
- Вместо пользовательского списка заявок администратор видит дашборд: уникальные посетители, регистрации, проекты, заявки и распределение проектов между тремя рабочими сервисами.
- Посещения учитываются на сервере по случайному идентификатору браузера без хранения исходного cookie; известные поисковые роботы исключаются.
- Добавлена миграция `010_admin_dashboard.sql`. Перед production-развёртыванием временный пароль необходимо заменить.

## 2026-09-24 — восстановление оформления «Плитка PDF»

- Публичные изображения PDF-редактора теперь разрешаются относительно `/services/pdf/`, поэтому логотип, фотографии и иллюстрации шаблонов работают внутри общей оболочки и в ранее сохранённых документах.
- В PDF-редактор возвращён исходный системный шрифт; внешнее переопределение Manrope удалено, чтобы сохранить оригинальные размеры, цвета и расположение блоков шаблонов.

## 2026-09-24 — перенос гостевых работ

- Гостевые проекты сохраняются в отдельном локальном реестре и автоматически переносятся в БД после входа или регистрации.
- Текущие состояния калькулятора и PDF-редактора переносятся из гостевого пространства в пространство нового аккаунта вместе с локальными библиотеками документов и шаблонов.
- Визуализатор автоматически сохраняет выбранную комнату, плитку по зонам, освещение и экспозицию без необходимости сначала выгружать изображение.
- Переход между разделами Tile Tools больше не вызывает системное предупреждение после локального автосохранения; для действительно незавершённой записи используется внутренний диалог сайта.
- Нативное предупреждение браузера сохранено только для закрытия самой вкладки в короткий момент до завершения локального сохранения, поскольку браузер не разрешает заменить его HTML-окном.

## 2026-09-24 — проекты и избранное аккаунта

- Серверные проекты и все типы избранного окончательно привязаны к ID пользователя; гостевой список больше не смешивается с аккаунтами через общий `localStorage`.
- Локальный рабочий кэш калькулятора, PDF-редактора и оболочки получил отдельное пространство имён для каждого пользователя.
- Страница «Избранное» показывает реальные записи текущего аккаунта и позволяет удалять их.
- «Сравни плитку» переведён с устаревшего поля `users.favorites` на общую таблицу `tt_favorite_items`.
- При несохранённых или не синхронизированных изменениях браузер предупреждает пользователя перед закрытием вкладки; после успешного автосохранения предупреждение снимается.

## 2026-09-24 — регистрация и токены входа

- Добавлена самостоятельная регистрация обычного пользователя по никнейму, почте и паролю; аккаунт активируется сразу.
- Пароли сохраняются только через `password_hash`, а при входе устаревший хеш автоматически обновляется.
- Реализован длительный вход по непрозрачному токену в HttpOnly/SameSite-cookie; в базе хранится только SHA-256-хеш секретной части токена.
- Токен ротируется при восстановлении сессии и отзывается при выходе; срок действия по умолчанию — 30 дней.
- Добавлена миграция `009_auth_tokens.sql`.

- В калькуляторе изображение выбранного материала теперь накладывается как текстура на каждую плитку: видны реальный цвет и орнамент, но выбранный формат не меняется.
- Раздел «Проекты» приведён к согласованному макету: добавлены поиск, фильтры, пользовательские статусы, избранное, архив и возврат в исходный сервис.
- Автосохранения калькулятора и PDF-редактора, а также успешные JPG-выгрузки визуализатора попадают в единый реестр; при возврате восстанавливается сохранённое состояние.
