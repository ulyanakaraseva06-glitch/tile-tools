# Встроенные исходники сервисов

В этой папке лежит исходный код приложений, которые составляют Tile Tools. Он хранится в общем Git-репозитории и не требует соседних папок на рабочем столе.

- `sravni-plitku` - PHP-визуализатор;
- `project_vilray_studio` - React-приложение расчёта;
- `plitka-pdf` - React-приложение PDF-редактора.

Не добавляйте в Git папки `node_modules`, `dist` и пользовательские результаты. После нового клонирования выполните из корня проекта `./scripts/setup-local.ps1`.
