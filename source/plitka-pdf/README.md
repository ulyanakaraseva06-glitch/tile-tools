# Плитка PDF от Vilray Studio

MVP веб-сервиса для быстрой сборки PDF-документов по плитке: мини-каталогов, коммерческих предложений, прайсов и подборок.

Проект собран как статический frontend на `React + Vite + TypeScript`. В рабочей папке хранятся только исходники, нужные ассеты и продуктовая документация. Временные артефакты сборки, логи и одноразовые исторические материалы не считаются частью постоянного состава проекта.

## Что входит в рабочее ядро

- `src/` — исходный код приложения, лендинга, legal-разделов и аналитики.
- `public/` — публичные ассеты, заглушки, изображения лендинга и PHP-обработчики аналитики.
- `app/`, `admin/`, `terms/`, `privacy/` — HTML-входы для отдельных страниц.
- `docs/` — актуальная документация по продукту, шаблонам, аналитике и исследовательским материалам.
- Корневые конфиги: `package.json`, `package-lock.json`, `tsconfig*.json`, `vite.config.ts`, `vitest.config.ts`, `eslint.config.js`.

## Правило хранения файлов

В проекте зафиксированы три класса файлов:

1. `runtime source` — код, ассеты и конфиги, нужные для запуска и сборки.
2. `project docs` — актуальная документация и исследовательские материалы в `docs/`.
3. `external archive` — старые ТЗ, промежуточные выгрузки, референсы, zip-архивы и прочие исторические материалы, вынесенные за пределы рабочей папки.

Если файл не нужен для запуска, сборки, тестов или текущей продуктовой работы, его место во внешнем архиве, а не рядом с приложением.

## Локальный запуск

```bash
npm install
npm run dev
```

Обычно локальный адрес Vite: `http://127.0.0.1:5173/`.

Основные входы:

- `http://127.0.0.1:5173/` — публичный лендинг.
- `http://127.0.0.1:5173/app/` — рабочее приложение.
- `http://127.0.0.1:5173/admin/analytics/` — экран аналитики.
- `http://127.0.0.1:5173/terms/` — условия.
- `http://127.0.0.1:5173/privacy/` — политика конфиденциальности.

## Проверка и сборка

```bash
npm run lint
npm run test
npm run build
npm run preview
```

Папка `dist/` считается одноразовым артефактом. Она создаётся заново при `npm run build` и не хранится как постоянная часть проекта.

## Где менять данные и тексты

- `src/data/defaultTexts.ts` — стартовые тексты и контакты.
- `src/data/pageTemplates.ts` — библиотека шаблонов страниц.
- `src/data/documentSchemes.ts` — схемы документов.
- `src/data/vilrayPromos.ts` — промоблоки Vilray.
- `src/styles/` — темы, layout-стили и модальные окна.
- `public/placeholders/` — заглушки и демонстрационные визуалы.
- `public/brand/logo.webp` — логотип сервиса.

## Документация

В `docs/` хранятся:

- продуктовые и технические заметки по шаблонам и аналитике;
- инструкции по деплою;
- исследовательские материалы по референсам, включая `REFERENCE_PILOT_2026-06-12.md` и связанный JSON.

Служебные browser-profile выгрузки, кэши и crash dump-файлы не относятся к документации и должны удаляться или выноситься во внешний архив.
