# Page Library Copy And Sorting

## Goal

Prepare naming, descriptions, and sorting rules for the upgraded page library before implementation.

## Sorting rules

- New benchmark templates should appear first inside their categories.
- Existing legacy templates remain below them.
- Search should match both title and description, so wording must describe the layout clearly.

## Title pattern

Use short titles that describe what the user gets visually.

Recommended pattern:

- `Cover / Hero interior`
- `Cover / Business`
- `Catalog / Interior + product`
- `Catalog / Sample grid`
- `Catalog / Interior left, products right`
- `Catalog / Moodboard`
- `Table / Technical icons`
- `Price / Visual quote`
- `Contacts / Next step`

## Description pattern

Descriptions should answer three questions fast:

1. What type of page is this?
2. What is the dominant composition?
3. When is it useful?

Recommended structure:

- composition first
- content second
- use case third

Example:

- `Large interior, one product accent, and a clean collection heading for the opening page.`
- `Sample grid with SKU captions and technical rhythm for assortment presentation.`
- `Technical page with icon blocks for size, finish, thickness, and usage.`

## Naming principles

- Avoid vague names like `Template 1`, `Catalog modern`, or `Premium page`.
- Prefer explicit selection language.
- A user should understand the page from the library list even before opening the thumbnail.

## Suggested library copy for the first wave

### `cover_catalog_hero`

- Title: `Cover / Hero interior`
- Description: `Large interior, one product accent, and a clean collection heading for the opening page.`

### `cover_catalog_business`

- Title: `Cover / Business`
- Description: `Calm opening page for commercial offers with quick facts, product focus, and manager-friendly structure.`

### `catalog_product_hero`

- Title: `Catalog / Interior + product`
- Description: `Interior image, large tile presentation, and compact characteristics for a key product page.`

### `catalog_sample_grid`

- Title: `Catalog / Sample grid`
- Description: `Multiple samples with article, format, and surface captions for assortment presentation.`

### `catalog_interior_products_split`

- Title: `Catalog / Interior left, products right`
- Description: `Sales layout with one strong interior and a clear column of product positions.`

### `catalog_moodboard`

- Title: `Catalog / Moodboard`
- Description: `Material-focused page with several textures and minimal text for visual direction.`

### `table_technical_icons`

- Title: `Table / Technical icons`
- Description: `Fast-reading technical page with icon blocks for size, finish, thickness, and usage.`

### `price_visual_quote`

- Title: `Price / Visual quote`
- Description: `Visual support block with calculation table and totals for commercial presentation.`

### `contacts_next_step`

- Title: `Contacts / Next step`
- Description: `Closing page with contacts, follow-up action, and a calm final visual.`

## Preview tie-in

- Thumbnail composition should match the title language.
- If the title says `Sample grid`, the thumbnail must clearly show repeated swatch rhythm.
- If the title says `Technical icons`, the thumbnail must show icon-led blocks immediately.
