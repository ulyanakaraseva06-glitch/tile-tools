# Проверка перед выпуском

## Код и сборка

- `npm ci` устанавливает зависимости без изменения lockfile.
- `npm audit` не показывает известных уязвимостей.
- `npm run lint` проходит без ошибок.
- `npm run test` проходит полностью.
- `npm run build` создаёт production-сборку в `dist/`.

## Страницы

- `/` открывает публичный лендинг.
- `/app/` открывает редактор документов.
- `/admin/analytics/` открывает актуальный экран аналитики.
- `/terms/` и `/privacy/` открывают legal-страницы.
- Логотип и изображения лендинга загружаются без битых ссылок.
- Лендинг корректно работает на мобильном и desktop-экране.

## Редактор

- Стартовый документ создаётся и отображается.
- Страницы добавляются, дублируются, сортируются и удаляются.
- Тексты, изображения, списки и таблицы редактируются.
- Изменения сохраняются в локальное хранилище.
- Сохранённые документы и шаблоны повторно открываются.
- История изменений, отмена и повтор работают ожидаемо.

## Импорт и экспорт

- Проект экспортируется и импортируется через JSON.
- Проверка документа перед PDF показывает страницы и предупреждения.
- PDF скачивается в выбранной ориентации.
- Все страницы попадают в один файл без искажения изображений.

## Аналитика и публикация

- Клиентские события отправляются в `/api/analytics/`.
- Admin API отвечает после настройки PHP/MySQL и токена.
- На хостинг публикуется содержимое `dist/`, а не исходники.
- `node_modules`, `dist`, логи и временные файлы не остаются в постоянном составе проекта.
