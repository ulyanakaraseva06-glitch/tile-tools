Scope of this pilot:
- Ignore broken and encrypted PDFs for now.
- Ignore obvious duplicate copies with ` (1)` suffix.

Selection principles:
- Cover Italy, Spain, and Russia.
- Include both large general catalogs and narrow-format books.

## What to extract from this pilot

- Covers:
  premium hero covers, architectural covers, restrained text-first covers
- Catalog overview:
  series opener, collection story, collection index
- Catalog interior:
  scene + SKU, scene + one product, scene + companion products
- Visual focus:
  full interior + slab, two interiors + key slab, vertical room + slab
- Grid pages:
  color matrix, family grid, compact novelty assortment, accessory assortment
- Technical:
  application pages, outdoor systems, installation logic, spec tables, workbook pages
- Moodboard/editorial:
  texture boards, material pairing, visual narrative, premium pacing

## Expected outcomes from the pilot

- Confirm which page logics recur across very different brands.
- Identify 8-12 high-value new page patterns for the app library.
- Separate reusable commercial patterns from beautiful but non-transferable editorial spreads.
- Build a stable shortlist before scaling analysis to all 86 PDFs.
