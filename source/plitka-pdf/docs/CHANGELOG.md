# Changelog

## Stage-01 MVP

- Создан React/Vite/TypeScript-проект.
- Реализован desktop-first рабочий интерфейс.
- Добавлены пресеты: мини-каталог, КП, прайс, подборка, пустой документ.
- Добавлена библиотека шаблонных страниц.
- Реализовано редактирование текстов, изображений, списков и таблиц.
- Добавлено изменение порядка страниц, дублирование и удаление.
- Добавлено автосохранение в `localStorage`.
- Добавлен импорт и экспорт JSON.
- Добавлен PDF-экспорт через `html2canvas + jsPDF`.
- Добавлена финальная проверка документа перед скачиванием.
- Добавлены локальные демо-плейсхолдеры.
- Подготовлена документация и архивы этапа.

## Stage-01 UI Update

- Добавлен новый логотип; актуальная WebP-версия хранится в `public/brand/logo.webp`.
- Верхнее меню упрощено: скрыты импорт/экспорт JSON и отдельный предпросмотр.
- `Тип документа` переименован в `Шаблон`.
- Поле названия проекта оформлено как понятный input.
- Тема и акцент теперь меняют PDF-документ, а не интерфейс сервиса.
- Добавлен выбор формата: A4 вертикально / A4 горизонтально.
- Добавлены локальные «Мои документы» без backend.
- Библиотека страниц стала сворачиваемой по категориям.
- Добавлен zoom и полноэкранный просмотр текущей страницы.
- Нижняя лента страниц зафиксирована в рабочей области и не расширяет интерфейс.
- Добавлено автосжатие изображений и лимиты строк/пунктов.
- Подпись `plitka-pdf.ru` в PDF оформлена заметной брендированной плашкой.

## Stage-01 Interface And Template Update

- Плашка названия проекта уменьшена по ширине.
- Выбор готового шаблона перенесён в левую библиотеку страниц.
- Поиск в библиотеке переименован в `Поиск`.
- `Формат` переименован в `Ориентация`, варианты стали `Вертикально` и `Горизонтально`.
- Акцент документа больше не меняет интерфейс сервиса.
- Добавлена отдельная кнопка `Кабинет`.
- Кнопка `Сохранить` показывает статус сохранения под названием кнопки.
- Расширен диапазон масштаба страницы до 35-200%.
- Правая панель редактора получила единую белую подложку и аккуратный скролл.
- В кабинете добавлены рабочие настройки темы интерфейса и контактных данных.
- Добавлены новые варианты страниц каталога с интерьерными изображениями и акцентными плашками.
- Рендер изображений переведён на `background-size: cover/contain`, чтобы PDF не растягивал картинки.
