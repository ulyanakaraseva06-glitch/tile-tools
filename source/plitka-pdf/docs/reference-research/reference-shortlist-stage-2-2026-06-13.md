## Model switch rule

Stay on the current model for:
- indexing;
- duplicate grouping;
- rough catalog scoring;
- shortlist generation;
- file management.

Switch to a stronger vision model before:
- deciding exact page winners inside each catalog;
- comparing similar layout variants side by side;
- turning reference patterns into actual service templates.

That switch matters because the next step needs judgment on composition, spacing, and page-level visual hierarchy, not just catalog-level structure.
