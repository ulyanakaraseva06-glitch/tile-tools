# Документация «Плитка PDF»

«Плитка PDF» — веб-сервис Vilray Studio для сборки каталогов, прайсов, коммерческих предложений и клиентских подборок по плитке.

## Текущая архитектура

- Frontend: React, Vite и TypeScript.
- Стили: обычный CSS, разделённый по функциональным зонам.
- Проекты и настройки: локальное хранение в браузере.
- Импорт и экспорт проектов: JSON.
- PDF: клиентский экспорт через `html2canvas` и `jsPDF`.
- Аналитика: клиентские события и PHP/MySQL API на хостинге.
- Основное приложение не требует отдельного Node.js-сервера в production.

## Основные команды

```bash
npm install
npm run dev
npm run lint
npm run test
npm run build
npm run preview
```

## Состав документации

- `STRUCTURE.md` — актуальная структура проекта и политика хранения файлов.
- `DEPLOY.md` — сборка и публикация.
- `CHECKLIST.md` — проверка перед выпуском.
- `CHANGELOG.md` — история развития.
- Документы `CATALOG_*`, `PAGE_*`, `FIRST_WAVE_*`, `ICON_*` — развитие библиотеки шаблонов.
- `ANALYTICS_MYSQL_SETUP.md` и `analytics_schema.sql` — настройка аналитики.
- `REFERENCE_PILOT_2026-06-12.md` и связанный JSON — исследование каталожных референсов.

Старые ТЗ, архивы этапов и промежуточные выгрузки хранятся во внешнем архиве, а не в рабочей папке проекта.
