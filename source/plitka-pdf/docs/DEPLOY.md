# Deploy

## Локальная подготовка

```bash
npm install
npm run build
```

## Что загружать на хостинг

Загружать только содержимое папки:

```txt
dist/
```

Внутри будут:

```txt
index.html
assets/
placeholders/
```

## Что не загружать как публичную версию

Не загружать на публичный хостинг:

- `src/`;
- `node_modules/`;
- `docs/`;
- исходные `.md`-брифы;
- `package.json`;
- `package-lock.json`;
- временные файлы и архивы.

## Backend не нужен

Основному приложению не нужен Node.js-сервер в production. Node.js используется локально для установки зависимостей и сборки. PHP требуется только для подключённой серверной аналитики.

## Проверка после загрузки

- Главная страница открывается.
- Стили и плейсхолдеры загружаются.
- Можно выбрать зону на странице.
- Можно изменить текст.
- Можно загрузить изображение.
- JSON экспортируется и импортируется.
- PDF скачивается.
- На последней странице есть подпись `Создано в plitka-pdf.ru`.
