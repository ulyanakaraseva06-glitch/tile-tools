## Дефекты

### QA-001 — HTTPS публичного домена имеет неверный сертификат

- Серьёзность: Blocker.
- Шаги:
  1. Открыть `https://gamer-ok.ru/`.
  2. Дождаться проверки TLS.
- Факт: браузер показывает `net::ERR_CERT_COMMON_NAME_INVALID`.
- Ожидание: страница открывается по HTTPS без предупреждений.
- Дополнительно: `http://gamer-ok.ru/` работает; DNS и последний deployment корректны.
- Следующий шаг: проверить custom domain и выпуск сертификата HTTPS в GitHub Pages.

### QA-002 — нельзя корректно замкнуть нарисованное помещение

- Серьёзность: High.
- Автотест: `custom room drawing > allows the last point to match the first point and closes the contour`.
- Шаги:
  1. Перейти в «Нарисовать самому».
  2. Поставить минимум четыре корректные точки без самопересечений.
  3. Последнюю точку поставить точно на первую.
- Факт: возвращается «Линии помещения не могут пересекаться».
- Ожидание: контур замыкается, становится доступно завершение построения.
- Вероятное место: `src/canvas/drawing.ts`, `validateDraftPoint()`.

### QA-003 — второй проём на одной стене не создаётся

- Серьёзность: High.
- Автотест: `prevents overlapping openings on the same wall`.
- Шаги:
  1. Создать прямоугольное помещение 1700 × 2000 мм.
  2. Добавить дверь на стену 1.
  3. Повторно выбрать эту стену и добавить вторую дверь.
- Факт: `addOpeningDetailed()` возвращает `opening: null`.
- Ожидание: вторая дверь ставится в доступное место без наложения.
- Вероятное место: `src/project/projectFactory.ts`, `findOpeningPosition()`.

### QA-004 — сценарий соседних проёмов сломан

- Серьёзность: High.
- Автотест: `allows adjacent openings on the same wall`.
- Причина: второй проём из QA-003 не создаётся, поэтому дальнейшее перемещение вплотную невозможно.

### QA-005 — TypeScript-проверка приложения не проходит

- Серьёзность: Medium/High.
- Команда: `npx tsc --noEmit`.
- Факт: 11 ошибок.

- Ожидание: typecheck завершается с кодом 0.

### QA-006 — CI публикует проект без тестов и typecheck

- Серьёзность: High (процесс выпуска).
- Факт: workflow содержит только install, build и deploy.
- Риск: production получает известные регрессии.
- Ожидание: deploy зависит от успешных `npm test` и `npx tsc --noEmit`.

### QA-007 — две уязвимые production-зависимости

- Серьёзность: High/Moderate.

- Ожидание: `npm audit --omit=dev` сообщает 0 vulnerabilities.

### QA-008 — у правой панели разрешена общая вертикальная прокрутка

- Серьёзность: Medium, несоответствие согласованному UI.
- Факт: `.side-panel > .panel-stack.tile-panel-stack { overflow-y: auto; }`.
- Ожидание: основные блоки помещаются на одном экране; прокрутка допустима только внутри действительно длинных внутренних списков.

### QA-009 — отсутствует полноценное E2E-покрытие интерфейса

- Серьёзность: Medium.
- Не автоматизированы реальные drag-and-drop, визуальные наложения подписей, responsive-layout, keyboard navigation, скачивание/загрузка и последовательности undo/redo.
- Риск особенно высокий для canvas-интерфейса, где большая часть прошлых дефектов была именно визуальной или координатной.

## Ограничения этого прогона

- Desktop E2E выполнен при 1280 × 720; отдельный мобильный viewport не прогонялся.
- Файл открытия не загружался обратно, потому что браузерная загрузка локального файла требует отдельного подтверждения пользователя.
- Нажатия «Загрузить в PDF» и «Сохранить» выполнены, но встроенный браузер не зафиксировал событие скачивания; требуется проверка папки загрузок в обычном Chrome.
- Удаления проверены до окна подтверждения и отменены, чтобы не разрушать тестовый проект.
